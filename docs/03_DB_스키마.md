# 03. DB 스키마

- 기준: 사양서 §4.2 최소 컬럼 + 3차(승인)·5차(그룹) 컬럼을 미리 둔다.
- 정본은 `backend/alembic/versions/` 마이그레이션. 이 문서와 어긋나면 문서를 고친다.
- 시각은 전부 `timestamptz`, 서버 시각 기준. 단말 `ts`(KST, 분 단위, 오프셋 없음)는 참고값으로만 별도 보관.

## telemetry — 이력 (월 파티션)

```sql
CREATE TABLE telemetry (
  uuid         char(24)    NOT NULL,
  received_at  timestamptz NOT NULL,
  ts_device    text,                 -- 'YYMMDDThhmm' 원문
  sq           bigint,
  fw           text, ss int, cv int,
  er int, "on" smallint, md smallint,
  pw1 smallint, pw2 smallint, pw3 smallint,
  bv int, bi int, sc smallint, pp int, li int, cs int,
  raw          jsonb       NOT NULL, -- 원본 전체. 해석은 조회 시
  PRIMARY KEY (uuid, received_at)
) PARTITION BY RANGE (received_at);
-- 파티션: telemetry_YYYYMM. 백엔드 기동 시 + 매일 1회 "다음 달"까지 미리 생성,
-- 13개월 지난 파티션 DROP (TELEMETRY_RETENTION_MONTHS=13, 즉 1년 + 여유 1달)
CREATE INDEX ON telemetry (received_at);  -- 파티션마다 상속
```

- 숫자 컬럼을 풀어 두는 이유: 그래프·집계 쿼리에서 jsonb 파싱을 피하기 위해. 단위 변환(÷100)은 하지 않는다.
- `cs` 비트 해석은 저장하지 않는다(MPPT 레지스터 맵 변경 대비).
- 적재: 1초 배치 multi-row INSERT. 실패 시 그 묶음은 버리고 `telemetry_dropped` 카운터 증가.

## command — 서버 → 단말 명령

| 컬럼 | 비고 |
|---|---|
| `seq` bigint PK | 시퀀스 `cmd_seq` (uint32 범위 CHECK, 4,294,967,295 근접 시 경보) |
| `target_kind` | `device` / `group` / `all` |
| `target_id` | uuid 또는 group_id, all 은 NULL |
| `type` | PING / CMD / SCH / OTA / STATUS_GET … |
| `payload` jsonb | 보낸 그대로 |
| `expected_count` int | 대상 단말 수 (그룹/전체) |
| `acked_count` int | |
| `sent_at`, `finished_at` | |
| `result` | `OK` / `PARTIAL` / `TIMEOUT` / `FAILED` |

CHECK: `seq BETWEEN 0 AND 4294967295`, `target_kind IN ('device','group','all')`. 인덱스 `(target_id)`.
`expected_count` 기본 1, `acked_count` 기본 0. 2차는 `acked_count >= expected_count` 가 되면
`finished_at`·`result=OK` 를 채운다. PARTIAL/TIMEOUT 판정은 5차 타이머.

## 파티션 경계

`telemetry_YYYYMM` 의 FROM/TO 는 **UTC 월 1일 00:00** 이다(이름과 경계 문자열이 일치하도록).
일 집계(`telemetry_daily.day`)는 KST 날짜로 자른다 — 조회 범위이지 파티션 경계가 아니다.

## 원격 표시 채널별 (마이그레이션 0005, 2026-09-28, ADR-008)

단말 F/W 2026-09-27-9 가 개별 > 그룹 > 전체 계층 슬롯을 없애고 **채널마다 마지막에 받은 명령 하나**로 바꿨다(사양서 §3.10.8 개정).

| 컬럼 | 비고 |
|---|---|
| `device.override_ch` jsonb NULL | `{"1": {"act","seq","until","level"}, "2": {...}}` — 1 주등(PWM1), 2 입간판(PWM2), 3 PWM3. `until` = ISO 시각(보낸 ts + dur). `level` 은 경로 기록용 |

- `override_act/level/seq/until` 은 **가장 늦게 끝나는 채널**의 요약으로 같이 쓴다(`core/override.apply_channels`) — 목록 필터 `remote=true` 와 "원격 n분 남음"이 그대로 쓴다.
- 백필: `override_seq` 가 있던 단말은 그 명령 `payload.ch` 채널마다 같은 값(ch 없으면 1·2·3).
- 재부팅·현장 조작(md 1) TM 을 받으면 그 TM **이전에 보낸** 명령의 채널만 지운다(뒤에 보낸 명령 채널은 남긴다 — B11).
