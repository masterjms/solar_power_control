## 사양서 개정분(09-27)

- **채널마다 마지막 명령 하나(F/W -9)** — ADR-008, DB 0005 `device.override_ch`, `channels_after_ok`, 시뮬레이터 채널 슬롯, S5-05 개정.
- 현장 설정 저장(엔코더 SAVE 등)도 2초 뒤 TM(ss 오름) — 기존 `local_saved` 감지로 처리됨, 변경 없음.
- 현장 수동 `md` 변화 2초 TM — 기존 처리(주기 이상으로 보지 않음), 변경 없음.
- TLS: P-1 확정(루트 저장·서버 검증), RSA, TLS 1.2 — 위 #9.

## 판단한 것

- 전압 소수 1자리: 단말 기본값이 12.75 / 13.15 V(0.01 단위)라 반올림해 보이면 손대지 않아도 "바뀜"이 되고 쓰면 현장 값이 바뀐다 → 그런 값만 2자리.
- 일일 발전량·사용량 단위는 요청의 "W" 대신 **Wh**(전력량). 감축 계수 0.4781 kgCO2eq/kWh 는 `.env` 로 바꿀 수 있게 — 확정값 요청.
- 승인 버튼은 시설명·지역이 **저장돼** 있어야 열린다(개발 환경 `APPROVE_REQUIRES_NODE=false` 여도 화면은 요구).
