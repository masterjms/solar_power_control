## 확인
- 백엔드 단위 301(새 `test_accounts.py` 8), 도구 단위, 프런트 빌드 통과.
- **nginx 로그인 경로로 세 역할 47개 확인**(로컬, 시·도 2개 — 경기도·서울특별시):
  - 최고관리자: 계정 만들기, 잘못된 입력 422 칸별 이유, 최고관리자 4번째 거부, 서버 상태 200.
  - 지역관리자(경기도): 단말 목록·알람·지도·전력 통계 = 경기도만, 범위 밖 단말 상세·설정 404, 지역 트리에 서울 안 보임, 서울에 동 추가 403 `OUT_OF_REGION`·경기도에 동 추가 201, 지역 이름 바꾸기 403, 서버 설정·계정·서버 상태·통신 주기 설정 만들기 403(목록은 보임), 단말 삭제 403, 범위 밖·전체 명령 403·자기 시·도 명령 200, 뒤 6자리 검색.
  - 게스트: 대시보드 API 5종 200, 명령·스케줄·단말 상세 403 `GUEST_READ_ONLY`.
  - 사용 중지 → 쓰던 로그인 바로 401·로그인 거부 `ACCOUNT_DISABLED`, 내 비밀번호 바꾸기 → 쓰던 로그인 401·새 비밀번호 로그인, 로그인 기록에 실패 남음.
  - 시험 중 고친 것: ① 비밀번호를 바꾼 같은 초에 받은 쿠키가 살아 있던 것(쿠키가 초 단위) → 바꾼 시각을 다음 정수 초로 올림 ② 지역관리자가 새 동을 만들면 응답이 404 이던 것(요청 시작 때 계산한 범위에 새 노드가 없음) → 방금 만든 노드는 거르지 않음.
