## 시트 "보조 설명"에 넣을 문구

**2번** — [9/30 서버] 숫자 칸 폭을 줄이고(84→58px), 다단계는 이름 칸을 줄여 "시각(시계 아이콘 바로 옆) + 선택바 + %"가 한 줄에 보이게 했습니다. 화면이 좁으면 선택바가 시각 아래 줄로 내려갑니다. 배터리 전압 표시는 말씀대로 그대로 두었습니다.

**13번** — [9/30 서버] 핀을 법정동 등록 화면의 카카오 기본 핀과 같은 물방울 모양·크기로 키웠습니다. 몸통 색 = 통신(온라인 녹색, 오프라인 회색, 승인 대기 파랑), 속 원 = 조명(점등 노랑, 소등 흰색)입니다. 오프라인은 15번에 따라 소등으로 봅니다. 마우스를 올리면 "시설명 / 배터리 전압"은 그대로입니다.

**14번** — [9/30 서버] 서버 설정 파일(.env)의 COMMAND_TIMEOUT_SEC 입니다(지금 180초). 자동 재시도는 COMMAND_MAX_ATTEMPTS(3회), 재시도 최소 간격은 COMMAND_RETRY_MIN_SEC(20초)입니다. 화면에서 바꾸는 항목은 아니고, 바꾸면 서버 재시작이 필요합니다.

**15번** — [9/30 서버] 통신 두절(오프라인)이면 마지막 보고가 점등이어도 소등으로 표시·집계합니다. 대시보드 조명 상태(소등 = on=0·통신 두절), 단말 목록·대시보드 목록의 주등/입간판, 단말 상세, LED 제어 창, 지도 핀 모두 같습니다.

**16번** — [9/30 서버] 원인은 브라우저 기본 로그인 창(Basic auth)이었습니다. 카카오톡 등 앱 안 브라우저는 그 창을 띄우지 않고 바로 401을 보여 줍니다. 이제 사이트에 로그인 화면이 뜨고(계정은 기존과 같음), 로그인은 7일 유지, 오른쪽 위 "로그아웃"이 있습니다. 폰 화면도 맞췄습니다(메뉴는 위쪽 가로 줄, 카드는 한 줄). 배포 후 안드로이드·iOS(카카오톡 링크 포함) 확인 부탁드립니다.

**17번** — [9/30 서버] 스케줄은 9/29 배포본에 들어갔습니다. 사이드바 "스케줄 배포"에서 ① 프로필 만들기(지역·보정·운전 15개, 미리보기) ② 지역 트리에 배정(하위로 상속, 단말 예외 가능) ③ "이 노드 아래 배포" ④ 단말별 적용됨/응답 없음 확인 순서입니다. 오프라인 단말은 다시 접속하면 자동으로 받습니다. "일부 형태만 보임"이 이 화면이 아니었다면 어느 화면인지 알려 주세요.

**18번** — [9/30 서버] 지역은 손 입력 대신 전국 시·군 목록(특별·광역시 + 도 아래 시·군)에서 고릅니다. 고르면 지역명("경기도 군포시")과 시청·군청 좌표가 채워지고, 좌표는 필요하면 고칠 수 있습니다. 단말 설정의 1년 스케줄과 스케줄 배포 프로필 둘 다 같습니다. 군 지역 설치도 있을 것 같아 군도 넣었습니다 — 시만 원하시면 말씀 주세요.

**19번** — [9/30 서버] 반영했습니다. LED 제어 밝기는 "설치 기준 밝기 대비 %"로 표시하고, 채널마다 옆에 실제 출력(설치 기준 × 비율)을 보여 줍니다. 창을 열 때 처음 값은 켜져 있을 때 받은 실제 출력 ÷ 설치 기준이고, 모르면 100%(= 설치 기준 그대로)입니다. 통신 두절 ti × 3은 그대로 갑니다.
