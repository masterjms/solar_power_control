# 2026-10-07 문제점 43번(A안 화면 문구) · 45번(꺼진 승인 대기) · 46번(www.enerz.co.kr)

## 43 — 운영자 말로 정리(A안)
- 24개 화면 파일에서 개발 용어 약 100곳 정리: 지우기(§·API 주소·설정 파일 이름·N차·필드 이름) / 쉬운 말(docs/07 용어표) / 비교 숫자 → "같음·다름·반영 대기".
- 원문(JSON)·주소·명령 번호·지문 숫자는 `ui.Detail`("자세히", 접힘)로 — 최고관리자만 보인다. 단말측과 문제를 맞춰 볼 근거는 남김.
- 많이 바뀐 곳: 단말 상세(상태 버튼 "승인/거절/폐기/중지 해제", "승인 정보 다시 보내기", "연결 확인", 설정 반영 결과 문장, 이벤트 종류 한글),
  단말 설정(설정 비교·현장 저장·표 확인 결과 문장, 변경 이력의 스케줄 표), 승인 창, 원격 명령(결과 "모두 응답/일부 응답/응답 없음"),
  그룹 스케줄 변경(판 N, 단말과 같음/다름), 통신 주기 설정(보고 주기·접속 유지), 서버 상태(단말 통신 서버), 위쪽 알약, 알람 마지막 값.
- 확인: 프런트 빌드, 브라우저 12개 화면 + 단말 상세 3대 + 단말 설정에서 개발 용어 검색 0건.

## 45 — 꺼진 승인 대기 단말
- 등록·승인 목록·메뉴 숫자·대시보드 "승인 대기"는 켜져 있는 대기 단말만. "꺼진 단말도 보기 (n대)"로 펼쳐 거절·폐기 정리.
- API: `counts.PENDING_ONLINE` 추가. 확인(로컬): 대기 11대 모두 꺼짐 → 기본 0대, 펼치면 11대.

## 46 — www.enerz.co.kr 경고
- 원인: 가비아의 `www` 레코드가 이 서버가 아닌 다른 서버(호스팅 기본 — 다른 회사 인증서, 403)를 가리킴. 관제 서버 문제 아님.
- 서버: `40-tls.sh` 에서 `www.` 로 온 요청을 맨 도메인으로 301(쿠키·카카오 등록 주소 하나로). 임시 인증서 컨테이너로 확인 — www → 301 https://enerz.co.kr/…, 맨 도메인 401(정상).
- 남은 일(운영자): 가비아 `www` → EIP, 인증서에 www 추가(docs/04 §6.9).
