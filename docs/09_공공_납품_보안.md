# 09. 공공 납품 보안 기본 항목 (문제점 51·54번, 2026-10-17)

마을방송 70번과 같은 기준. "들어가 있는 것 / 설정 방법 / 남은 것" 순서.

## 1. 들어가 있는 것

| 항목 | 내용 | 어디서 바꾸나 |
|---|---|---|
| 접속 기록 | 로그인 성공·실패·잠김·잠금 해제, IP. 1년 보관(개인정보 안전성 확보조치 기준 1년 이상) | 계정 관리 → 로그인 기록 |
| 비밀번호 규칙 | 영문 대문자·소문자·숫자·특수문자 중 3종 8자 이상 또는 2종 10자 이상. 지금 비밀번호와 같으면 거부 | `core/accounts.password_problem` |
| 비밀번호 변경 주기 | 90일 지나면 로그인 직후 바꾸기 창(닫기 없음, 로그아웃만) | `PASSWORD_MAX_AGE_DAYS` |
| 관리자가 정한 비밀번호 | 새 계정·재설정 비밀번호는 본인이 로그인하면 바꿔야 쓸 수 있음 | `admin_user.must_change_password`(0012) |
| 연속 실패 잠금 | 5회 연속 틀리면 30분 잠금(잠긴 동안 맞는 비밀번호도 거부, 잠긴 동안 시도는 잠금을 늘리지 않음). 최고관리자가 "잠금 해제" 또는 비밀번호 재설정으로 풂. `.env` 계정도 같음 | 계정 관리 화면 |
| 무동작 자동 로그아웃 | 마우스·키보드·터치가 30분 없으면 로그아웃(10초 자동 갱신은 '사용'이 아님, 여러 탭 공유). 0 = 끔(벽 모니터 관제용) | 서버 설정 → 보안 |
| 로그인 시도 제한 | IP 당 분당 10회(nginx) + 실패 시 1초 지연 | `nginx.conf.template` |
| 전송 암호화 | HTTPS(TLS 1.2/1.3), HSTS 1년, 단말은 MQTT TLS 8883 | docs/04 §6 |
| 보안 헤더 | nosniff · X-Frame-Options SAMEORIGIN · Referrer-Policy · Permissions-Policy (+TLS 모드 HSTS) | `frontend/nginx/35-access.sh` |
| 관리자 접속 IP 제한 | `.env ADMIN_ALLOW_IPS`(쉼표로 여러 개, CIDR). 비우면 전체 허용. 단말·인증서 확인(/.well-known)·외부 감시(/healthz)는 막지 않음 | `.env` → `docker compose up -d web` |
| 권한 | 최고관리자·지역관리자(맡은 시·도만)·게스트(보기만), 사용 기간·사용 중지 | 계정 관리(21번) |
| 비밀번호 저장 | 관리 화면 PBKDF2-SHA256 24만 회, 단말 MQTT 비밀번호는 서버 키로 계산(저장 안 함)·브로커 파일은 PBKDF2-SHA512 해시 | — |
| 조작 기록 | 원격 명령·설정 변경·그룹 스케줄 보내기·서버 설정 변경의 "누가·언제", 최근 활동(관리 분류), 단말별 엑셀 내보내기 | 대시보드·단말 상세 |
| 로그 크기 상한 | 컨테이너 로그 20 MB × 5개 | `docker-compose.yml x-logging` |
| 백업 | 매일 03:10 DB 덤프(7일) + 디스크 스냅샷. 복구 절차 docs/04 §9 | cron |
| 설치형 납품 | 인터넷 없이 설치·업데이트하는 묶음(53번) | docs/08 |

설정 예 — 기관 관리자 PC 대역만 관리 화면 허용:
```bash
cd /opt/solar_power_control && sed -i 's/^ADMIN_ALLOW_IPS=.*/ADMIN_ALLOW_IPS=10.20.0.0\/16, 203.0.113.10/' .env && docker compose up -d web && docker compose logs web | grep "관리 화면 접근"
```
