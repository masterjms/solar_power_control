## 2. 단계별 서버 범위

사양서 §0 표를 서버 관점으로 다시 쓴 것. 각 단계는 앞 단계 합격 후 시작.

### 1차 — Broker 만 (진행 중)
- Mosquitto 1883, 공용 계정 `solarlte-test`, IP 제한
- 서버 응용 없음. 합격 = Broker 로그에 24자리 UUID Client ID
- 산출물: `infra/`, `docs/04_인프라_운영.md` §1차 런북

### 2차 — 수집 서비스 + DB + 단말별 계정 + CONFIG
- `register`/`status`/`result`/`event` 구독 → DB
- 단말 레코드는 topic UUID 로 upsert (REGISTER 는 보강 정보)
- `sq` 판정: 건너뜀=lost, 되돌아감=reboot
- 단말별 계정 + ACL (사양서 §1.1.2.2). CSV import → passwd/aclfile 재생성 → HUP
- CONFIG_SET/ACK. `cv_server != cv_device` 면 **다음 Telemetry 수신 시점**에 재전송(타이머 없음)
- 합격: 사양서 §1.1.8 "2차 합격 기준" 5개 → `tools/scenarios/` 로 자동화
- 1차 펌웨어 호환: `"t":"TM"` 과 `"type":"TM"` 둘 다 받음 (2차 펌웨어 확정 후 `t` 제거)

### 3차 — 승인 게이트 + 최소 관제
- 상태머신 PENDING/ACTIVE/SUSPENDED/REJECTED/RETIRED
- REGISTER_ACK 를 `config` topic 에 **retain** 으로. 받을 때마다 반드시 응답
- RETIRED 정리 = 빈 payload retain
- LWT 기반 Online/Offline. 모뎀 LWT 미지원(P-2)이면 `ti × 3` 무수신
- 관리 화면: 미승인 목록, 승인 버튼, site/lat/lon 입력 (플래그 편집 수준)
- 합격: 사양서 §3.9.1 5개 시나리오

### 4차 — MQTTS + 운영 Broker 분리
- 8883 TLS(LE 인증서), 1883 은 운영 계정 거부
- 서버 코드는 접속 설정만 변경

### 5차~7차 — 제어, 스케줄, 알람, OTA, 대시보드
- 5차: `CMD` 개별→그룹→전체. `exp`/`dur` 필수 검증. CMD_ACK 단말별 집계, 무응답만 개별 재시도
- 6차: SCHEDULE chunk, Event/Alarm, STATUS_GET
- 7차: OTA, 지도(cluster), 대시보드

## 4. aircast(xWIFI)에서 가져오는 것 / 바꾸는 것

가져옴: 단일 aiomqtt 연결(재연결 1→30초 backoff), publisher 단일 창구, DB 시퀀스 ID, `dedup_key` 중복 제거, 최신값 1초 배치 upsert, presence 단일 정의, passwd/acl 생성→감시 루프→HUP + ACL 적용 확인 후 CONFIG 발송, fd 65536, mock 단말 부하 시험.

바꿈:

| aircast | 여기 |
|---|---|
| MAC 식별 | UUID 24자리 대문자 |
| CONFIG retained | retained 는 REGISTER_ACK 뿐. CONFIG_SET 은 비retain, 다음 Telemetry 때 재전송 |
| online = 300초 고정 | LWT 우선, 대체는 단말별 `ti×3` |
| 비밀번호 평문 저장 | 해시만. 평문은 PC 도구 CSV 에만 |
| 최신값만 | 최신값 + 이력(파티션) |
| 자동 등록 즉시 사용 | 3차부터 승인 게이트 |

## 5. 대규모·안정성 고려 (1만 대)

- 평균 부하: 10분 주기 17 msg/s, 1분 주기여도 167 msg/s. 문제 없음
- **재접속 폭주**: 브로커 재시작 후 1만 대가 30초 안에 REGISTER. 서버 응답(REGISTER_ACK+CONFIG_SET)은 토큰 버킷으로 초당 상한. 단말측 backoff 지터 확인 요청(사양서에 없음 → TBD 추가 요청)
- **DB 장애**: 이력 flush 실패 시 버리고 카운트(무한 적체 금지). 최신값 버퍼는 UUID 키라 단말 수 이상 안 커짐
- **브로커 재시작**: 자동 재구독. `persistence true` 로 retained REGISTER_ACK 보존
- **fd**: mosquitto 컨테이너 nofile 65536
- **모니터링**: `/health` + 수신률·flush 실패·버퍼 크기 카운터. Prometheus 는 4차 이후 검토
